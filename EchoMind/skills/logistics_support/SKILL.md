# 物流异常案件处理
只处理疑似丢件、签收争议、破损错发。先核对订单与运单归属，再查询轨迹。
所有演示订单、轨迹和工单必须说明是模拟数据。签收记录不等于本人收件，不直接认定丢件或责任。
破损错发要求外包装、面单和商品问题材料；当前仅记录用户声明，未实现图片上传与审核。
建单前需要用户本轮明确回复“确认建单”。不保证承运商受理、赔付、退款或处理时限。
政策无覆盖、事实冲突或查询失败时保存案件，提示人工核查。Skill 不能替代代码权限与状态校验。
