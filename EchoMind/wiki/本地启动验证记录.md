## 本机启动方式

在 EchoMind 后端目录运行：

```powershell
docker compose -f docker-compose.yml -f docker-compose.local-check.yml up -d --no-build --pull never
docker compose -f docker-compose.yml -f docker-compose.local-check.yml ps
```

查看接口：http://localhost:8000/docs 。当前启动的是后端服务，没有启动独立 Web 前端和 Java 后端。

## 本机网络适配

Docker Hub 当前不可达。Python、Redis、Nginx 使用 Docker Official Images 在 Amazon ECR 的发布源拉取并映射为原本地标签；Prometheus 从官方 quay.io/prometheus/prometheus 发布源拉取。
应用镜像依赖已按 requirements.txt 安装。向量模型从同一 Chroma 官方 S3 桶分段下载并校验压缩内容，SHA256 为 913d7300ceae3b2dbc2c50d1de4baacab4be7b9380491c27fab7418616a16ec3，通过临时 Dockerfile 和命名构建上下文导入；原 Dockerfile 没有修改。
新增 docker-compose.local-check.yml，使 ChromaDB 复用应用镜像中的 chromadb==0.5.23 服务进程，避免拉取不可达的 Docker Hub 镜像；这是本机联调用覆盖配置。后续启动请同时携带两个 -f 参数。
