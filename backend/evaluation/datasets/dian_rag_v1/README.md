# DiAn RAG 业务标注草稿

`corpus.json` 固定现有六篇默认知识和三篇物流演示规则，沿用知识库 500 字分块、文档身份与内容版本。`queries.json` 有 30 条自建开发样本，其中 27 条带候选证据，3 条涉及语料缺失的赔付政策或实时业务事实。`manifest.json` 保存源文件和产物哈希。

全部样本为 `pending_human_review`。候选证据及必要事实由本轮整理，两位复核者字段为空。原文包含某段文字只证明引用可追溯，问题条件、答案充分性、其他片段的相关性及知识缺失仍需要人工核对。没有经过完整相关性标注的片段保持未判断状态。

复核时先读问题及候选原文，再检查剩余语料中的替代证据、相近但条件不适用的段落。两位复核者独立填写身份和意见，分歧保留裁决记录。修订样本后重新生成快照版本与哈希。当前数据只用于准备业务验收，尚无已冻结的业务测试集。

公开检索实验使用 MIRACL 中文训练集的固定子集，数据与该业务草稿分开存储。下载、候选池及实验边界见[验收说明](../../../wiki/DiAn-A3检索评测最小接入验收.md)。
