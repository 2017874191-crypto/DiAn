# 物流异常案件处理
只处理疑似丢件、签收争议、破损错发。先核对订单归属；提供运单时还须匹配订单。疑似丢件、签收争议须查询轨迹。
所有演示订单、轨迹和工单必须说明是模拟数据。签收记录不等于本人收件，不直接认定丢件或责任。
破损错发仅提交人工审核：核验归属并记录外包装、面单和商品问题材料声明后征求确认，不依赖物流查询。未查询物流不得说已核验轨迹。当前未实现图片上传与审核，提交不代表图片真实、责任认定或赔付获批。
建单前需要用户本轮明确回复“确认建单”。不保证承运商受理、赔付、退款或处理时限。
政策无覆盖、事实冲突或必要查询失败时保存案件，提示人工核查。Skill 不能替代代码权限与状态校验。
