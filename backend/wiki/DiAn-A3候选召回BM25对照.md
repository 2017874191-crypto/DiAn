# A3 候选召回 BM25 对照

在代码 `73c9c09` 上完成 30 题、299 段固定共享标注池的离线比较。BM25 在 29 题的前二十条中找回至少一个已知正例，向量基线为 19 题。BM25 补回向量漏掉的 11 题，同时丢失一道向量命中的题。直接取 BM25 前三命中 19 题，提供了值得继续验证的简单检索基线。

## 实验约束

复用[首轮六组报告](../evaluation/rag_30q_first.json)中 `budget_rerank` 实际召回的二十个候选 ID，向量模型为现有 Chroma all-MiniLM-L6-v2。脚本核对语料 manifest 哈希、全部问题 ID、原查询哈希和候选身份。向量检索结果采用上轮实测记录，本轮仅测 BM25 本地索引与查询耗时，两者的时延没有做配对比较。

BM25 复用开源 [rank-bm25](https://github.com/dorianbrown/rank_bm25) 的 `BM25Okapi`，依赖固定为 0.2.2，仅加入可选评测依赖文件。参数预先采用 k1=1.5、b=0.75、epsilon=0.25。输入与向量索引相同，仅使用段落正文。预处理为 NFKC、转小写，将连续 Unicode 字母数字序列切成重叠字符二元组，单字符序列保留。标点形成分界。平分按段落 ID 升序。无停用词、繁简转换或参数搜索。

每题预算同为二十个候选。BM25 不足二十条正分候选时用零分结果按固定顺序补齐，逐题记录正分候选数量。核对发现，本次所有被找回的已标注正例分数均大于零，命中统计未受零分补齐影响。模型调用为 0。

## 丢失案例与边界

BM25 唯一整题丢失为 `3425282#0`，查询是“日环食发生的原理是什么？”。向量找回的已标注段落 `746377#9` 以繁体文字解释月球本影和“日環食”。字符形式差异可能影响词面匹配，尚未单独做繁简转换消融。本轮保留这次损失，全部问题中两种召回同时漏失的题数为零。这个互补现象提供后续研究方向，当前先评估简单方案。

语料使用上游标注正负段落的并集，仅有 299 段，正例已保证存在于其中。BM25 的词面优势可能受候选库构造影响，未标注跨题段落以零增益计分。这些数字适用于本开发池，业务语料与更大语料上的效果仍需评估。脚本逐题记录新增、丢失正例 ID，未以当前排序调整金标。

下一轮优先比较 BM25 直接前三与同一 BM25 二十条经过现有重排后的前三，测量额外调用能找回多少正例、是否损害原已命中问题，以及 nDCG、P95 和 token 的变化。固定检索候选后只改变重排机制。

## 复现与验证

先按[语料准备说明](DiAn-A3检索评测最小接入验收.md)恢复固定快照。在 backend 目录执行。

```powershell
python -m pip install -r requirements-rag-eval.txt
python -m evaluation.compare_rag_candidates --output data/rag-a3/candidate-bm25.json
```

[逐题结果](../evaluation/rag_candidate_bm25.json)保存源码身份、依赖摘要、基线文件哈希、完整候选与分数和分组指标。实际运行检查了 30 个问题与旧报告的对应、每题二十个唯一候选、全部 11 个新增命中与 1 个丢失命中。重复运行的候选与质量结果一致，本地耗时随机器负载变化。
